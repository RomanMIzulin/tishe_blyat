# Менеджмент напряжения

**[v1 — «Тише»](v1/README.md)**: сервис для работы с психологическим напряжением в моменте. Интерфейс на Elm 0.19.3: дневник состояния, практики внимания и телесные практики, философские/психоаналитические основания.

```sh
cd v1
npm ci
npm run dev
```

Открыть http://localhost:5173. Подробности хранения данных, проверки и ограничения — в [документации v1](v1/README.md).

## Публикация

Адрес GitHub Pages после успешного деплоя: **https://romanmizulin.github.io/tishe_blyat/**.

В **Settings → Pages** выбери **Source: GitHub Actions**. После push в `main` workflow проверяет приложение, собирает сайт для `/tishe_blyat/`, запускает браузерные тесты и публикует готовую сборку. [Подробности и локальная проверка](v1/README.md#github-pages).

В Git хранятся исходники, lockfile, тесты и документация. Зависимости, кэши Elm, сборка, локальные настройки окружения и отчёты тестов исключены через `.gitignore`.

## Разработка с Pi

[AGENTS.md](AGENTS.md) — правила разработки; [DESIGN.md](DESIGN.md) — визуальный язык и смысл сервиса; [GLOSSARY.md](GLOSSARY.md) — термины.

Запускай Pi из корня проекта. После разрешения загрузки локальных ресурсов доступны шаблоны из `.pi/prompts/`:

- `/feature <описание>` — реализовать изменение с проверками.
- `/review [файлы или фокус]` — проверить изменения, не редактируя исходники.

После добавления или изменения шаблонов выполни `/reload`. Если Pi запущен из `v1/`, перезапусти его из корня, чтобы загрузить корневые `.pi/prompts/`.
